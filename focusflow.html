Set up Google Sheets
  1. Paste the downloaded script into a separate Google Apps Script project.
  2. Set script properties FOCUSFLOW_SHEET_ID and FOCUSFLOW_SYNC_KEY. Use a random key of at least 32 characters.
  3. Deploy as a web app running as the owner. Select Anyone if your account permits public web app access. The sync key is required to write.
  4. Enter the deployment URL and sync key above, then send a summary.
